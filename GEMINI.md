# LakehouseBox

This extension connects the LakehouseBox MCP server (it reads, and writes only when the person approved write) and ships skills under `skills/`. Before any LakehouseBox
task, read `skills/lakehousebox/SKILL.md`; for Portolan geospatial catalogs, also `skills/lakehousebox-portolan/SKILL.md`.
Each skill names the reference file to open next.
